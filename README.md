# Rishitha R Kumar — 3D Data Analytics & Business Intelligence Portfolio

This repository contains the source code for the professional 3D personal portfolio and branding website for **Rishitha R Kumar**, Aspiring Data Analyst & Business Intelligence Specialist. Built with React 18, TypeScript, Three.js, React Three Fiber, Rapier Physics, and GSAP.

---

## 📂 Project Structure

- `3d-portfolio-main/` — Main React + Vite + Three.js project folder
  - `src/` — React components, shaders, animations, and styles
  - `public/` — Static assets, 3D models, textures, project preview graphics, and official resumes
    - `Rishitha_R_Kumar_Resume.pdf` (Official ATS Resume)
    - `Rishitha_R_Kumar_Resume.docx` (Official ATS Word Document)
    - `Rishitha_R_Kumar_Resume.html` (Editable source)

---

## 🚀 Getting Started

```bash
cd 3d-portfolio-main
npm install
npm run dev
```

Visit `http://localhost:5173` to explore the live 3D portfolio!
