# Rishitha R Kumar — 3D Data Analytics & Business Intelligence Portfolio

This repository contains the source code for the professional 3D personal portfolio and branding website for **Rishitha R Kumar**, Aspiring Data Analyst & Business Intelligence Specialist. Built with React 18, TypeScript, Three.js, React Three Fiber, Rapier Physics, and GSAP.

---

## 🌟 Highlights & Features

- **Hero & 3D Interactive Scene**: Dynamic kinetic typography, 3D interactive model scene, and responsive personal branding.
- **Data Analytics & BI Showcases**: Highlighting executive Power BI dashboards, ETL pipelines, and DAX architectures.
- **Experience Timeline**: Detailed career progression featuring internships at Global Quest Technologies, Deloitte (Forage), and Cognifyz Technologies.
- **Interactive 3D Physics Tech Stack**: Physics-driven dynamic sphere simulation featuring Power BI, Python, SQL, Tableau, Excel, Pandas, MySQL, and OpenCV.
- **Core Competencies & Verified Credentials**: Comprehensive categorical skills matrix and verified certifications.
- **Resume Integration**: Direct 1-click download of the ATS-compliant resume (`Rishitha_R_Kumar_Resume.pdf`) and editable Word document (`Rishitha_R_Kumar_Resume.docx`).

## 🛠️ Tech Stack

- **Frontend & Framework**: React 18, TypeScript, Vite

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) and [npm](https://www.npmjs.com/) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/rishitharkumar/3d-portfolio.git

# Navigate to the project directory
cd 3d-portfolio-main

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Build for Production

```bash
npm run build
```
